# OpenClaw Control Plane — Phase 2 新增需求文档

> 创建时间：2026-03-31 | 基于用户反馈 + 全网竞品调研

## 一、用户明确需求（P0 必做）

### 1.1 国际化（i18n）
- **需求**：所有界面文案支持中英文切换，一键切换语言
- **范围**：导航栏、表格列名、按钮、状态标签、空状态提示、表单标签、弹窗标题等
- **技术方案**：前端引入 `react-i18next`，建立 `locales/zh.json` + `locales/en.json` 两套翻译文件
- **切换入口**：右上角语言切换器（🌐 图标下拉）
- **持久化**：用户语言偏好存 localStorage
- **覆盖范围**：100% 文案，零硬编码中文/英文

### 1.2 功能丰富化 + 详情页
- **需求**：当前功能太少，列表项无法点开查看详情
- **新增页面**：
  - **项目详情页** `/projects/:id`：项目基本信息、所属任务列表、进度统计、时间线
  - **任务详情页** `/tasks/:id`：任务完整信息、状态变更历史、评论/备注、依赖关系、关联文件
  - **Agent 详情页** `/agents/:id`：Agent 状态、心跳记录、负载指标、执行历史
- **列表增强**：
  - 项目列表：支持搜索、按状态筛选、排序
  - 任务列表：支持多字段筛选（状态/优先级/项目/负责人）、批量操作（删除/状态变更）
  - 看板页：增加 WIP 限制提示、快速创建任务卡片

### 1.3 全网调研新增功能
基于 Jira、Linear、Asana、OpenProject、Mission Control、ClawStaff 等竞品分析，新增以下功能模块：

#### A. 活动流 / 时间线（Activity Feed）
- 全局活动流页面，记录所有项目的操作日志（创建/修改/删除/状态变更）
- 每条记录含：操作人、操作类型、时间、关联对象、变更前后对比
- 支持按项目/类型/时间筛选

#### B. 甘特图（Gantt Chart）
- 项目级别的甘特图视图，展示任务时间线
- 支持拖拽调整任务时间
- 依赖关系可视化（连线）
- 里程碑标记

#### C. 团队管理 / 成员面板
- 成员列表：姓名、角色、当前任务数、工作量统计
- 成员详情：分配的任务、近期活动、效率指标

#### D. 数据统计 / 分析面板（Analytics）
- 项目进度分布饼图
- 任务状态分布图
- 团队工作量热力图
- 交付趋势折线图（每日/每周完成任务数）
- 逾期任务统计

#### E. 全局搜索
- 顶部搜索栏，支持搜索项目/任务/Agent
- 搜索结果分类展示
- 支持关键词高亮

#### F. 通知中心
- 未读通知徽标
- 通知列表：任务分配、状态变更、逾期提醒、评论提及
- 标记已读/全部已读

#### G. 回收站
- 已删除的项目/任务进入回收站
- 支持恢复（30天内）
- 永久删除

#### H. 快捷键支持
- 全局快捷键：`Cmd/Ctrl+K` 呼出搜索
- 列表页：`J/K` 上下移动、`X` 选择、`E` 编辑、`N` 新建

### 1.4 主题切换
- **需求**：支持多主题切换
- **预设主题**：
  1. **暗色主题（Dark）**：深色背景，适合夜间使用（当前默认）
  2. **亮色主题（Light）**：白色背景，清爽风格
  3. **赛博朋克（Cyberpunk）**：紫+霓虹色，科技感
  4. **森林绿（Forest）**：绿色系，护眼
  5. **Ocean（海洋）**：蓝色系，沉稳
- **技术方案**：CSS Variables + 主题 token 文件，切换时替换根节点 CSS 变量
- **切换入口**：右上角主题切换器（🎨 图标下拉预览色块）
- **持久化**：用户主题偏好存 localStorage

## 三、技术约束

- 前端框架：React + TypeScript + Vite + TailwindCSS
- 后端：FastAPI + SQLite（当前）/ PostgreSQL（后续）
- 状态管理：无（当前），建议引入 zustand
- UI 组件：纯 CSS / TailwindCSS（当前），不引入 antd 等重型库
- i18n 方案：react-i18next
- 主题方案：CSS Variables + data-theme 属性
- 所有新功能必须同时支持中英文

## 四、验收标准

1. ✅ 语言切换后 100% 文案跟随变化，无遗漏
2. ✅ 项目/任务列表可点击进入详情页，详情页信息完整
3. ✅ 至少 2 个主题可切换，切换后立即生效
4. ✅ 全局搜索可用，结果准确
5. ✅ 所有页面响应式，移动端可用
6. ✅ 所有新功能有对应的 API 端点
7. ✅ 后端测试覆盖新增 API
8. ✅ 前端构建无报错（`vite build` 通过）
