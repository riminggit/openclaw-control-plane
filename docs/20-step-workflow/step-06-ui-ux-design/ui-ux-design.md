## 🎨 设计规范

### 1. 设计原则
- **清晰性**：信息层次清晰，操作明确
- **一致性**：统一的视觉语言和交互模式
- **效率性**：减少用户操作步骤
- **反馈性**：及时反馈操作结果

## 4. 页面设计

### 4.1 模板列表页 (/workflows)
**布局**：网格布局，卡片展示
**功能**：
- 顶部：标题 + 创建按钮
- 搜索栏：搜索框 + 状态筛选 + 刷新按钮
- 内容区：模板卡片列表
- 底部：分页控制

### 4.2 模板详情页 (/workflows/template/:id)
**布局**：单列布局
**功能**：
- 顶部：模板名称 + 状态标签 + 操作按钮
- 基本信息卡片
- DAG 可视化卡片
- 步骤列表卡片

### 4.3 创建模板页 (/workflows/templates/create)
**布局**：表单布局
**功能**：
- 基本信息：名称、描述输入
- 步骤编辑：添加/删除/排序步骤
- DAG 配置：设置依赖关系
- 预览：实时 DAG 预览

### 4.4 实例详情页 (/workflows/instance/:id)
**布局**：多卡片布局
**功能**：
- 顶部：实例信息 + 控制按钮
- DAG 执行进度可视化
- 步骤执行列表
- 日志输出

## 5. 交互设计

### 5.1 加载状态
- 页面加载：显示 Spin 组件 + "加载中..." 文字
- 按钮操作：按钮显示 loading 状态
- 数据加载：卡片骨架屏

### 5.2 错误处理
- API 错误：显示错误提示卡片，提供重试按钮
- 表单错误：输入框下方显示错误信息
- 操作失败：显示 Toast 提示

### 5.3 成功反馈
- 操作成功：显示成功 Toast（message.success）
- 数据保存：按钮状态变为"已保存"

## 6. 响应式设计

### 6.1 断点
```
- xl: ≥1600px
- lg: ≥1280px (主要支持)
- md: ≥1024px
- sm: ≥768px (不主要支持)
```

### 6.2 适配策略
- 桌面端（1280px+）：完整布局
- 小屏幕（<1280px）：横向滚动或简化布局

---

## 7. 可访问性

### 7.1 键盘导航
- 所有交互元素支持 Tab 键导航
- Enter/Space 触发操作

### 7.2 颜色对比度
- 文字与背景对比度 ≥ 4.5:1
- 符合 WCAG AA 标准

### 7.3 屏幕阅读器
- 使用语义化 HTML
- 添加 aria-label 属性
