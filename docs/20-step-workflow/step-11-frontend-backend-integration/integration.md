## 🐛 已修复的联调问题

### 问题 1: 无限循环导致页面闪烁
**发现时间**：2026-04-02
**问题描述**：前端页面一直闪烁，无法正常使用
**原因分析**：
- `useTemplates` hook 的依赖项 `params` 每次渲染都是新对象
- 导致 `useCallback` 不断重新创建 `fetch` 函数
- `useEffect` 检测到 `fetch` 变化，不断触发 API 请求
- 形成无限循环

**解决方案**：
```typescript
// 修复前
const fetch = useCallback(async () => {
  // ...
}, [params])  // ❌ params 每次都是新对象

// 修复后
const paramsKey = JSON.stringify(params)
const fetch = useCallback(async () => {
  // ...
}, [paramsKey])  // ✅ 使用稳定化的 key
```

**修复状态**：✅ 已修复并部署
